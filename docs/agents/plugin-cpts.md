# Plugin content model

The `custom-post-types-dp` plugin: loader, post types, taxonomies, meta, settings, Job Roles and Interests.

Master plugin `custom-post-types-dp` (version in the plugin header of `custom-post-types-dp.php`, `wp-content/plugins/custom-post-types-dp/`; `includes/class-loader.php` globs and requires every file in `includes/documents/`, `includes/post-types/`, `includes/settings/` and `includes/seeders/`, in that order and by file name within each folder, on `plugins_loaded`, skipping `index.php`) loads portfolio modules from `includes/post-types/*.php`. The Document, Collateral and Video types share their URL, Software Tools and Post Statistics sanitisers and their Software Tools, Post Statistics and Highlight meta boxes through `includes/post-types/media-meta.php` (`cptdp_media_*`). Each module hooks its `register_post_type` call to the `cptdp_register_post_types` action (fired on `init` and on plugin activation, followed by a rewrite flush). Registered CPTs: `service` (`includes/post-types/service.php`, hierarchical, title/editor/page-attributes, archive `/services/`, seeder `services` with `parent` column = parent title), `statistic` (`includes/post-types/statistic.php`, public, archive `/statistics/`, title/editor/order, seeder `statistics`), `software_tool` (`includes/post-types/software-tool.php`, public, archive `/software-tools/`, title/editor/thumbnail/order, meta `cptdp_site_url`, admin list columns), `video` (`includes/post-types/video.php`, public, archive `/videos/`, title/editor/thumbnail/order, menu position 33, taxonomies `video_category` and `aspect_ratio`, meta `cptdp_video_file` (video attachment ID), `cptdp_embed_url`, `cptdp_post_url`, `cptdp_length` (seconds), `cptdp_software_tools` (array of `software_tool` IDs), `cptdp_highlight`, `cptdp_post_statistics` (array of `{label, value}` string rows, repeater meta box); `custom-fields` support only exposes meta in REST, its meta box is removed; `assets/admin-video.js` media picker; admin list columns; seeder `videos` creates 6 test 9:16 videos from YouTube/Vimeo embed URLs and assigns one `aspect_ratio` and one `video_category` term each, `ddev wp cptdp seed videos`, needs both term seeders run first, no uploaded files; **autofill (v0.29.0, DPV-041)**: only on the wp-admin form save (`cptdp_video_save_meta()` calls `cptdp_video_autofill()` in `includes/post-types/video-autofill.php`; never the seeder, WP-CLI, REST or a page view) the Length and the Aspect ratio term (nearest of the four seeded terms, kept when an editor picked another; meta `cptdp_ratio_auto`/`cptdp_ratio_source`) come from the uploaded file (core's getID3) or the Vimeo oEmbed `duration` (YouTube stays empty, no API key) and the featured image from the embed (YouTube `maxresdefault` then `hqdefault` from i.ytimg.com, Vimeo oEmbed) or, for an uploaded file, a frame the admin's browser draws and sends to `POST cptdp/v1/videos/<id>/poster`; a typed Length or an image an editor chose is never replaced (post meta `cptdp_length_auto`/`cptdp_length_source` mark what the system wrote; ownership of images is `CPTDP_Generated_Image`, shared with `CPTDP_Page_Featured`); failures save anyway and show a one-time notice; filter `cptdp_video_autofill` (default true) turns the outbound calls off; existing videos are filled the next time they are saved in wp-admin).

**Manual preview clip (v0.32.0, DPV-040):** the Video edit screen has a Preview clip field (`cptdp_video_preview_pick`, media picker); a picked MP4/WebM under the 8 MB cap (`cptdp_video_preview_pick_ok()`, magic bytes) becomes `cptdp_video_preview` and replaces the generated clip (`cptdp_video_preview_apply_pick()`); a manual clip is never deleted by the system, clearing the field only unlinks it.

**Preview clip (v0.30.0, DPV-041):** for an uploaded file the admin's browser cuts the first 6 s into a muted H.264 MP4 (longest side 720 px, about 1 Mbps) with the vendored Mediabunny 1.66.0 (`assets/vendor/mediabunny/`, MPL-2.0, WebCodecs), falling back to `MediaRecorder` (real time), shows progress under the file name (`assets/admin-video-preview.js`, started by `admin-video.js` after the thumbnail frame) and uploads it to `POST cptdp/v1/videos/<id>/preview` (MP4 or WebM by magic bytes, 8 MB cap, filter `cptdp_video_preview_max_bytes`); the attachment ID is the REST meta `cptdp_video_preview`, what we made is in non-REST `cptdp_video_preview_generated` (attachment meta `_cptdp_generated_for`/`_from` = `file:<id>`); a preview we did not make is never replaced or deleted, ours is deleted when the file is removed, in Media or with the video; embeds get none; every generated thumbnail (embed download or the browser's frame) goes through `cptdp_video_trim_bars()` (GD): it crops a picture centred between two mirrored hard vertical seams (YouTube's blurred side fill) and solid black bars on both opposite edges, only when at least 20% of the image is left, and leaves everything else untouched; a big file (100 MB or more, filter `cptdp_video_warn_bytes`) gets a confirm in the media picker and a persistent note in the Video File box suggesting YouTube/Vimeo and the Embed URL instead (the box also shows the server's upload limit; the real limit is PHP's `upload_max_filesize`/`post_max_size`, DDEV sets 1024M (the lowest Hostinger plan, Web Single) in `.ddev/php/upload.ini`; on Hostinger set `upload_max_filesize` and `post_max_size` in hPanel > PHP Configuration (plan maximums: 1024 MB Single, 1536 Premium, 2048 Unlimited), the same on any other host, since a WordPress filter cannot raise PHP's limit); the aspect ratio is autofilled too (`cptdp_ratio_auto`/`cptdp_ratio_source`). `document` (`includes/post-types/document.php`, public, archive `/documents/`, title/editor/excerpt/thumbnail/order (the excerpt is the modal description), menu position 31, taxonomy `document_category`, meta `cptdp_document_file` (attachment ID, anything but video or audio; images are allowed), `cptdp_embed_url`, `cptdp_filetype`, `cptdp_author`, `cptdp_total_pages`, `cptdp_software_tools` (array of `software_tool` IDs, side meta box), `cptdp_highlight`, `cptdp_post_statistics` (array of `{label, value}` string rows, repeater meta box); `custom-fields` support only exposes meta in REST, its meta box is removed; `assets/admin-document.js` media picker and statistics repeater; admin list columns). `collateral` (`includes/post-types/collateral.php`, public, archive `/collaterals/`, title/editor/thumbnail/order, menu position 32, taxonomy `collateral_category`, meta `cptdp_collateral_file` (attachment ID, non-video/audio), `cptdp_embed_url`, `cptdp_paper_size`, `cptdp_total_pages`, `cptdp_software_tools` (array of `software_tool` IDs), `cptdp_highlight`, `cptdp_post_statistics` (array of `{label, value}` string rows, repeater meta box); `custom-fields` support only exposes meta in REST, its meta box is removed; `assets/admin-collateral.js` media picker and statistics repeater; admin list columns, incl. **Page images** status and a Thumbnail that falls back to page 1; the shared **Page images** meta box, see *Collateral page images* below). Registered taxonomies: `video_category` (`includes/post-types/video-category.php`, flat, public, rewrite `/video-category/`; attached to `video`, listed under the Videos menu, seeder `video-categories` creates `AI Generated`/`Short Form`/`Video Edits`, skipping an existing term by slug or name, `ddev wp cptdp seed video-categories`; the temporary top-level menu only shows when `video` does not exist). `aspect_ratio` (`includes/post-types/aspect-ratio.php`, flat, not public, no rewrite, seeded once via option `cptdp_aspect_ratio_seeded` with terms `16x9`/`9x16`/`1x1`/`4x3`, default term `16x9`, single-select meta box; attached to `video`; seeder `aspect-ratios` restores missing terms on demand, `ddev wp cptdp seed aspect-ratios`). `document_category` (`includes/post-types/document-category.php`, flat, public, rewrite `/document-category/`; attached to `document`, listed under the Documents menu, seeder `document-categories` creates `Certificates`/`Executive Docs`/`Operations Docs`/`Presentation Decks`/`Reports`, skipping an existing term by slug or name, `ddev wp cptdp seed document-categories`; the temporary top-level menu (position 26) only shows when `document` does not exist). `collateral_category` (`includes/post-types/collateral-category.php`, flat, public, rewrite `/collateral-category/`; attached to `collateral`, listed under the Collaterals menu, seeder `collateral-categories` creates `Flyer`/`Logo`, skipping an existing term by slug or name, `ddev wp cptdp seed collateral-categories`; the temporary top-level menu (position 28) only shows when `collateral` does not exist). The loader also requires `includes/settings/*.php` (Settings API modules that self-hook on `admin_menu`/`admin_init`). Seeders: `includes/seeders/*.php` each register one seeder via the `cptdp_seeders` filter (`label`, `callback( bool $dry_run, string $csv_path )`, `csv`, `post_type` or, for a term seeder, `taxonomy`, `columns`); shared helpers in `includes/cli/seeder-helpers.php` (`cptdp_get_seeders()`, `cptdp_run_seeder()`, `cptdp_seed_read_csv()`, `cptdp_seed_title_exists()`), the `wp cptdp seed` command in `includes/cli/class-seed-command.php` (loaded only under WP-CLI). Settings pages: Settings → Documents (`includes/settings/documents.php`, three sections: "Documents" with the book title, page image mode and margins; **"Document conversion"** (DPB-027), whose intro says once what is true of every converted format (made on the server when a document is saved, may differ from the original, a PDF export is best) and which has one read-only status field per family from `cptdp_documents_conversion_formats()` (label, file kind, converter name and the one detail line specific to it; `cptdp_documents_render_conversion_status()` shows Available with the version, or Unavailable with the reason, then the detail; a new format is a new table entry); and one **"Native viewer"** section with a checkbox per format that lets our own viewer take over the rendering, with selectable text and a closer match to the original at the expense of performance, the stored page images being the fallback; formats today are PDF, PowerPoint and Excel (`cptdp_documents_native_formats()`), DOCX is coming in a later ticket; the defaults, the sanitiser, the REST schema and the form loop are all derived from that list and `cptdp_documents_checkbox_keys()`, so a new format is one edit plus its label and help text), option `cptdp_documents` (`show_book_title`, boolean, default false: when off the title under each shelf book is hidden and the cover keeps it; read via `cptdp_get_documents_settings()`); Settings → Contact (`includes/settings/contact.php`), stored in option `cptdp_contact` (`email`, `whatsapp_url`, `linkedin_url`, `portrait_id`, `hero_title`); read via `cptdp_get_contact()`. Settings → Videos (`includes/settings/videos.php`): option `cptdp_videos`, nine booleans for the mobile video viewer (`cptdp_videos_mobile_options()` is the single list), read via `cptdp_get_videos_settings()`; `progress` is forced on by `scrub`.

**Job Roles and the Home hero (DPH-001, DPH-003, DPH-004, plugin 0.35.0):** `includes/post-types/job-role.php` is the `job_role` CPT (not public, no archive, title and page order, menu position 24, classic editor, REST on; `custom-fields` is in `supports` so the highlight is writable over REST, and its core meta box is removed). Meta `cptdp_highlight` marks the one role the hero shows as the main role; marking a role clears the mark on every other role on the meta hooks (`cptdp_job_role_single_highlight`). Seeder `job-roles` (`ddev wp cptdp seed job-roles`, `data/seeders/job-roles.csv`). Settings > Contact (`cptdp_contact`) also holds `portrait_id` (attachment ID of a PNG or WebP, media picker `assets/admin-contact.js`, read with `cptdp_get_contact( 'portrait_id' )`, an integer) and `hero_title` (default `David John`; a blank value makes the hero use the site title; read with `cptdp_get_contact( 'hero_title' )`). Both are in the one Contact section, with Portrait first. Settings seeder `portrait` (`data/seeders/portrait.csv`, `data/seeders/portrait/portrait.png`, a test photo to replace before launch) sets `portrait_id` only when none is set. The theme's hero is `blocks/hero/` (below).

**Interests and the Contact scheduler (DPH-025 to DPH-028, DPB-017, plugin 0.34.0):** the `interest` CPT (`includes/post-types/interest.php`, `interest-admin.php`) is not public, has no REST and no Add New, and holds the Home Contact submissions (title = name, content = message, meta `cptdp_email`, `cptdp_ip`, `cptdp_slot_utc` (the requested time in UTC, ISO 8601 with `Z`), `cptdp_visitor_local` (the time as the visitor entered it), `cptdp_visitor_tz`, `cptdp_services`, `cptdp_spam_check`, `cptdp_mail_sent`, `cptdp_seen`); it has a read-only view, a sidebar badge of unopened items (menu position 21, right after Pages and before Statistics, lock icon) and Trash enabled. The custom status `potential-spam` hides a submission from All and the badge and gives it its own tab with Not spam. `cptdp_akismet_check()` asks Akismet before a submission is saved (key from `WPCOM_API_KEY` or the Akismet plugin's `wordpress_api_key`, filter `cptdp_akismet_key`; fails open); the visitor's IP is stored on the Interest, the browser and referrer go only to Akismet. The contact request endpoint (`includes/settings/contact-request.php`) is `POST cptdp/v1/contact-request`: public on purpose, with a honeypot (`website`), 10 requests per hour per client (transient, filters `cptdp_contact_rate_limit` and `cptdp_contact_client_ip`). It validates, rate-limits, checks with Akismet, saves an Interest (`publish` or `potential-spam`) and emails the Settings → Contact address unless it is spam. `cptdp_contact_time_slots()` (six sensible times, 10:00, 11:00, 13:00, 14:00, 15:00, 16:00, filter `cptdp_contact_time_slots`), `cptdp_contact_window()` (tomorrow to +365 days in the site zone), `cptdp_contact_service_options()` (top-level Services, then `other`), `cptdp_contact_config()` are the single source for the endpoint and the theme. The visitor picks a day and time in their own zone (the browser's); the endpoint converts it to UTC in that zone (Settings → General's zone when none is sent) and stores the UTC instant with the entered time and zone. Stored times are UTC (requested time `cptdp_slot_utc`, received time `post_date_gmt`); the Interests screens show them in the admin's browser zone through `assets/admin-interest.js`, and Dave's email gives his site-zone time and the visitor's entry.
**Singular document category names (v0.24.0, DPD-036):** `document_category` terms store optional `cptdp_singular_name` term meta, exposed in REST and editable from the category forms. `cptdp_get_term_singular_name()` returns the stored value or the original term name; the document cover and modal payload use it, while the shelf filter pills remain plural. The category seeder CSV has a `singular` column and fills only empty existing values; run `ddev wp cptdp seed document-categories` to backfill existing terms. Tests live in `tests/taxonomies/test-document-category-singular.php`, `tests/taxonomies/test-categories.php`, `tests/seeders/test-document-categories.php`, and the theme document-book tests.
