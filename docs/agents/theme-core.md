# Theme core

theme.json, templates, parts, functions.php and the reusable software tags block.

## Theme architecture (`wp-content/themes/devportfolio/`)

Block (FSE) theme, intentionally tiny (no patterns, style variations, images or build step; bundled assets are the Hanken Grotesk font files and shared archive stylesheet). Design lives in data, not PHP, and follows the lo-fi wireframes: greyscale (palette `base` #fff, `contrast` #222, `mid` #8a8a8a, `line` #c9c9c9, `fill` #eee), Hanken Grotesk for everything (self-hosted in `assets/fonts/`, latin subset, weights 200-800, declared as `fontFace` in `theme.json`; the `sans` and `serif` presets are the same family, the modal's former Georgia titles use `var(--wp--preset--font-family--sans)`), 14px body, h3 as the 34px/800 page title (the Documents title is the exception: `.documents-page__title`, 44-72px, weight 200, -0.04em, as in the hi-fi), 1040px content width.
- `theme.json` — palette, typography, spacing, layout, global and block styles (incl. main navigation: 14px/500 links, 34px tall, hover `fill`, active page a filled ink pill; the menu button, the header title and the sticky frosted-glass header (blur on `header.wp-block-template-part::before`, never on the header itself, which would trap the fixed phone menu overlay; `--site-header-height` is what the mobile category strip sticks under) are in the top-level `styles.css`)
- `templates/` — `index`, `archive`, `search`, `single`, `page`, `404`, `archive-document`, `archive-collateral` (Documents page: `<h3>Documents</h3>` plus empty `documents-page__content` container for the category buttons and shelf). `archive-collateral` (Brand Collaterals): `<h3>Brand Collaterals</h3>`, the category pills, then `devportfolio/collateral-grid`; `<main>` has `collaterals-page` (no size rules of its own: it shares the Documents page shell in `page.css`, 1440px content and the same gutter), `archive-video` (Videos page: `<h3>Videos</h3>`, the `devportfolio/document-categories` block with `taxonomy` `video_category` and label "Video categories", then `devportfolio/video-grid` and, after it, `devportfolio/video-modal`; `<main>` has `documents-page videos-page`, `videos-page` has no rules of its own).
- `parts/header.html` — site title (on the left at 900px and below and from 1024px; hidden from 901 to 1023px, where the links sit at the left and Contact stays an outlined pill at the right), and main navigation, 7 inline links (core collapses at 600px and has no breakpoint attribute, so theme.json overrides its two `min-width: 600px` rules at 900px; from 1024px the header is a grid: title left, links centred, Contact an outlined pill pinned right) (Home, Services, Documents, Videos, Collaterals, Testimonials, Contact) with root-relative URLs, centred, core mobile overlay; `parts/footer.html` — the `devportfolio/site-footer` block (copyright with the current year and the site name on the left, LinkedIn, WhatsApp and Email from Settings → Contact on the right; the Email link shows the address from 601px up and the word "Email" below that; a link without a value is not shown)
- `functions.php` — the navigation link filter, block registration, the page/Home enqueues and the Home reveal script (everything that uses `__DIR__` or whose hook order is the CSS order), then `require_once` of `inc/core.php` (redirects, memo, published IDs, term slugs, page sources, shared labels and payload base), `inc/documents.php`, `inc/collaterals.php`, `inc/videos.php`, `inc/viewer.php` (modal markup shared by the three viewers) and `inc/home.php` (hero, Selected work, contact). A new helper goes in the file of its page; a helper two pages use goes in `inc/core.php` or `inc/viewer.php`. Never move a function that uses `__DIR__` into `inc/`.
- `blocks/software-tags/` — reusable dynamic block `devportfolio/software-tags` (DPD-016), registered in `functions.php`, `usesContext: ["postId"]`, attribute `limit` (default 2). Renders the post's published `software_tool` names (`devportfolio_software_tool_names( $post_id )`, works for any post type storing `cptdp_software_tools`: document, video, collateral; also used by the modal payload) as `ul.software-tags` of `li.software-tags__item`, text separated by a gradient dot; nothing when there are none. Items after `limit` get `software-tags__item--extra` and, when there are any, a `li.software-tags__more` (`+N`, `title` lists the hidden names) follows. At 480px and below the extras are hidden and `+N` is shown; above that every tag shows. Colours are local tokens; the size is `--software-tags-size` (default 13.5px, 12.5px at 820px and below) so a parent can override it. Use it with `<!-- wp:devportfolio/software-tags /-->` inside a post context, or from PHP with `new WP_Block( array( 'blockName' => 'devportfolio/software-tags' ), array( 'postId' => $id ) )`. Tests: `tests/test-software-tags.php` (`Devportfolio_Test_Software_Tags`).
- `style.css` — theme header only
- `tests/` + `phpunit.xml.dist` — the theme test suite (main navigation, `Devportfolio_Test_Navigation`, `@group theme`); the bootstrap loads the WP test lib and the plugin; see Tests for the command and what it covers
