# Seeders

Seeder data, rules and how to add one. The commands stay in AGENTS.md.

Data lives in `wp-content/plugins/custom-post-types-dp/data/seeders/<name>.csv` (edit the CSV, not the code). Seeders are idempotent: an item whose title already exists (any status, incl. Trash) is skipped, never modified. Content, not structure: never run on activation. The whole CSV is validated before any write. Thumbnails are added manually in wp-admin. `ddev snapshot` before a real run on a DB you care about.

Adding a seeder: (1) CSV in `data/seeders/<name>.csv` with a header row incl. `title`; (2) `includes/seeders/<name>.php` that adds its entry to the `cptdp_seeders` filter and defines the callback (copy `software-tools.php`; use `cptdp_seed_read_csv()` and `cptdp_seed_title_exists()`); (3) `tests/seeders/test-<name>.php` extending `CPTDP_Seeder_Test_Case` (implement `seeder_name()`, add column-mapping assertions). `list` is a reserved seeder name. `--all` order: `aspect-ratios`, `collateral-categories`, `document-categories`, `job-roles`, `portrait`, `services`, `software-tools`, `statistics`, `video-categories`, `videos`, `collaterals`, `documents` (the videos seeder needs both term seeders first; `collaterals` needs `collateral-categories` and `software-tools`, and `documents` needs `document-categories` and `software-tools`, so their files are `includes/seeders/z-collaterals.php` and `z-documents.php` to be required last: seeders run in file-name order). The `documents` seeder creates 9 published documents (excerpt = description, `cptdp_filetype`, `cptdp_total_pages`, `cptdp_author`, one `document_category`, `cptdp_software_tools` from `|`-separated tool titles; no uploaded files, no cover style), `ddev wp cptdp seed documents`. The `collaterals` seeder creates 6 published collaterals (description in `post_content`, since the type has no excerpt; `cptdp_paper_size`, `cptdp_total_pages`, `cptdp_highlight`, one `collateral_category`, `cptdp_software_tools` from `|`-separated tool titles, `cptdp_post_statistics` from `|`-separated `label:value` pairs split on the first colon; orientation is only a `paper_size` label such as `A4 Landscape`; no uploaded files or thumbnails), `ddev wp cptdp seed collaterals`. Term seeders (`aspect-ratios`, `collateral-categories`, `document-categories`, `video-categories`) recreate a term deleted in wp-admin, since terms have no Trash; WP always recreates a taxonomy's default term (`16x9`) on the next request.
