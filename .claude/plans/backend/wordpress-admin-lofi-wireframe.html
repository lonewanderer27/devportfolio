WordPress Admin – Sidebar & Post Editor wireframe v1

What Dave sees in the WordPress admin once the Dave Portfolio plugin is active: the left sidebar (A) and the create / update screen for every content type in the backend user stories (B, C). Everything in the first frame is live: click sidebar items, open a list, press Add New or a title, leave the title empty and press Publish, add statistic rows, pick files. Section G maps every story to a screen.

Responsive (mobile)

WordPress admin already collapses its menu under 782px; this keeps that and adds one proposed convenience
TopicRule
SidebarHidden under 700px. A ☰ in the top bar opens it as a left drawer over a #0007 backdrop; same items and order. Tap outside or ✕ to close
Edit screenSingle column: title, description, custom boxes, then Publish, Page Attributes, Thumbnail, taxonomies, tools, highlight. Collapsible boxes help keep the page short
RepeatersLabel and Value stack (full-width), ✕ stays at the right; the drag handle is hidden on touch and ▲ ▼ reorder is proposed
Publish bar (proposed)A sticky bottom bar with “Save Draft” and “Publish / Update” so the primary action is always in reach. Not native WordPress; confirm before building
ListsTable collapses to title rows with the key value under the title; row tap opens edit
TargetsButtons, rows, checkboxes and ✕ at least 44 × 44px on phones
UseDave mostly edits on desktop; mobile is for quick fixes, so no mobile-specific features beyond the above
