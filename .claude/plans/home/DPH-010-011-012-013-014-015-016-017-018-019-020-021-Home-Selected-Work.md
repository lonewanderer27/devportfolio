## 1. Goal and acceptance criteria

The Home page gets a **"Selected work"** section under "What I do": a bold heading and three cards (Documents, Videos, Brand collaterals). Everything a card shows comes from posts the owner already has, picked with the existing **"Mark as highlight (Selected work)"** checkbox (meta `cptdp_highlight`) that Documents, Videos and Collaterals already carry. Nothing new is created for Home.

**DPH-010 Layout**
1. Heading `Selected work` above the cards, bold (weight 800, same size as "What I do").
2. Desktop: row 1 has Documents and Videos side by side (equal width, 20px gap); row 2 has Brand collaterals across the full width. Order is fixed: Documents, Videos, Brand collaterals.
3. Each card: soft grey (`fill`, #eee), 1.5px ink outline, 14px radius, 30px padding, height 300px; text on the left, visual on the right, on the same line.

## 4. Decisions (made; do not reopen)

**D1. "Picked by Dave" = the existing `cptdp_highlight` flag.** Up to 4 documents, 5 videos and 6 collaterals, published only, in Order then title order (`devportfolio_work_picks()`). No new setting, no fallback: a content type with nothing ticked shows its text and no visual (nothing is invented for Home). The owner ticks the posts in wp-admin.

**D2. One dynamic block `devportfolio/selected-work`** renders the three cards (one `render.php`, one `style.css`, one `view.js`); the three viewers are the existing `document-modal`, `collateral-modal` and `video-modal` blocks placed right after it in `front-page.html` (the same way the archives place a modal after its grid).

**D3. Widths follow the shared Home shell** (`documents-page`, up to 1440px, the same as the stats strip and the services): the two row-1 cards are equal `1fr` columns with a 20px gap, so they are "about 480px" at the wireframe's 980px page and wider on big screens. Two columns above **1000px**, one column at 1000px and below (a card needs about 460px for its text column plus the fan or the strip).

**D4. At 620px and below every card stacks its visual under the text** (DPH-010 AC4 wins) and the card height becomes `auto`. The phone sizes of DPH-012 AC5 (62px books) and DPH-016 AC5 (112px strip) apply there, and the visual is aligned **right** ("stays on the right").

**D5. Collaterals glimpse sizing.** A piece's width is `min( base * ratio, base * 0.8 )` (so a square comes out shorter and a wide voucher or coupon comes out as a thin strip), height from its ratio. A piece with ratio >= 1.8 shares a column with the strip before it (voucher over coupon, 12px apart); every other piece has its own column; at most **5 columns** (so up to 6 ticked collaterals can show 5 columns when two are strips). The base height is a CSS variable: 176px, 120px at 900px and below, 84px at 620px and below.

**D6. Only the front book is a control** (D10 does the same for the strip). The other books carry `inert` (set on first paint by PHP and kept in step by the script), so keyboard focus and clicks only reach the book in front; the side books are decoration. Every book is a real `<button>` whose accessible name is the title.

**D7. What pauses a rotation:** pointer over the card (mouse or pen, never touch), keyboard focus-visible inside the card, the card off screen (under 25% visible), a hidden tab, and **any open `<dialog>`** (this is "the Home motion is paused while the viewer is open"). The clock only counts while running, so a pause does not skip or repeat a step.

**D8. Reduced motion:** the script does not start the book rotation and does not run the strip loop; the first book and the first clip stay in front, no video is loaded, and the strip's badge, time (`0:00`) and bar (empty) are drawn in their resting state. CSS also removes the transitions and the equalizer animation.

**D9. Video preview is loaded by the script only.** PHP writes no `<video>`; the active frame gets `data-preview-src` (the stored preview clip, else the uploaded file) and the script creates a muted, looping, inline `<video>` for the **middle frame only**, after the card has been on screen, and removes it when the frame stops being the middle one. Embed-only clips, data saver and reduced motion keep the poster; the time and the bar still run (except under reduced motion).

**D10. Only the middle frame is a control.** Each frame holds a `button.work-strip__open[data-video-id]` laid over it, named by the clip title; the other frames carry `inert` (PHP on first paint, the script afterwards), so only the active frame can be reached or clicked. Opening uses the Videos modal's plain fade (no fly-out, see Facts). The frame itself has no `role` or label.

**D11. Initial roles are written by PHP** (`data-role` on every book and frame) and the script takes over with the same rules from `rotation.js`; a PHP test and a Node test pin the same tables, so the page is right before and without JavaScript.

<?php
/**
 * Dev data only (never committed): gives every highlighted video without a featured image a grey 9:16 poster.
 * Run once: ddev wp eval-file wp-content/uploads/dev-posters.php

require_once ABSPATH . 'wp-admin/includes/image.php';

$ids = get_posts(
	array(
		'post_type'      => 'video',
		'post_status'    => 'publish',
		'posts_per_page' => 5,
		'fields'         => 'ids',
		'meta_key'       => 'cptdp_highlight',
		'meta_value'     => '1',
		'orderby'        => array(
			'menu_order' => 'ASC',
			'title'      => 'ASC',
		),
	)

foreach ( $ids as $index => $id ) {
	if ( has_post_thumbnail( $id ) ) {
		continue;
	}

	$image = imagecreatetruecolor( 360, 640 );
	$grey  = 90 + ( $index * 25 );
	imagefill( $image, 0, 0, imagecolorallocate( $image, $grey, $grey, $grey ) );
	$tmp = wp_tempnam( 'poster.png' );
	imagepng( $image, $tmp );

	$attachment = media_handle_sideload(
		array(
			'name'     => "poster-{$id}.png",
			'tmp_name' => $tmp,
		),
		$id
	);

	if ( is_wp_error( $attachment ) ) {
		echo $attachment->get_error_message() . "\n";
		continue;
	}

	set_post_thumbnail( $id, $attachment );
	echo "Poster added to video {$id}\n";
}

	 * @param int $index Frame position in the list.
	 * @param int $count Number of frames.
	 * @return string active, prev, next, far-prev or far-next.
	 */
	function devportfolio_work_frame_role( $index, $count ) {
		$offset = $index > $count / 2 ? $index - $count : $index;

		if ( 0 === $offset ) {
			return 'active';
		}
		if ( -1 === $offset ) {
			return 'prev';
		}
		if ( 1 === $offset ) {
			return 'next';
		}

		return $offset < 0 ? 'far-prev' : 'far-next';
	}
endif;

if ( ! function_exists( 'devportfolio_work_piece_columns' ) ) :
	/**
	 * Groups the collateral pieces into the glimpse's columns (DPH-020).
	 *
	 * A wide strip (ratio 1.8 or more, such as a 5:2 voucher or a 2:1 coupon) shares a column with the strip before
	 * it, so the two are stacked; every other piece has a column of its own. At most `$max` columns.
	 *
	 * @param array<int,array{ratio:float}> $pieces Pieces in display order.
	 * @param int                           $max    Most columns.
	 * @return array<int,array<int,array{ratio:float}>>
	 */
	function devportfolio_work_piece_columns( array $pieces, $max = 5 ) {
		$columns = array();

		foreach ( $pieces as $piece ) {
			$last     = count( $columns ) - 1;
			$is_strip = $piece['ratio'] >= 1.8;

			if ( $is_strip && $last >= 0 && 1 === count( $columns[ $last ] ) && $columns[ $last ][0]['ratio'] >= 1.8 ) {
				$columns[ $last ][] = $piece;
				continue;
			}

			if ( count( $columns ) >= $max ) {
				break;
			}

			$columns[] = array( $piece );
		}

		return $columns;
	}
endif;

if ( ! function_exists( 'devportfolio_work_piece_art' ) ) :
	/**
	 * The artwork inside a glimpse piece: the same picture the Brand Collaterals page shows (DPH-020).
	 *
	 * Page 1 of the stored page images (its thumbnail, with the larger page as the other candidate), else the featured
	 * image, else nothing (the piece stays a blank page).
	 *
	 * @param array $preview Result of devportfolio_collateral_preview().
	 * @return string HTML, escaped.
	 */
	function devportfolio_work_piece_art( array $preview ) {
		if ( 'page' === $preview['kind'] ) {
			return sprintf(
				'<img class="work-piece__img" src="%1$s" srcset="%2$s" sizes="180px" width="%3$d" height="%4$d" alt="" loading="lazy" decoding="async">',
				esc_url( $preview['src'] ),
				esc_attr( $preview['srcset'] ),
				(int) $preview['width'],
				(int) $preview['height']
			);
		}

		if ( 'featured' === $preview['kind'] ) {
			return wp_get_attachment_image(
				$preview['featured_id'],
				'medium',
				false,
				array(
					'class'    => 'work-piece__img',
					'sizes'    => '180px',
					'alt'      => '',
					'loading'  => 'lazy',
					'decoding' => 'async',
				)
			);
		}

		return '';
	}
endif;

/**
 * Pure rules for the two rotations on the Home "Selected work" cards (DPH-013, DPH-017).
 *
 * No DOM here: view.js reads the page and applies what these functions return.
 */

/** Documents change every 3.5 s, videos every 4 s, so the two cards are never in step (DPH-013 AC4). */
export const BOOK_PERIOD = 3500;
export const FRAME_PERIOD = 4000;

/** Position in a cycle of `count` items, 0 for the active one, counting forward: 0 .. count - 1. */
function forwardOffset( index, active, count ) {
	return ( ( ( index - active ) % count ) + count ) % count;
}

/**
 * Where a book sits in the fan: 'front', 'right' (next in line), 'left' (the one that was in front last) or 'hidden'
 * (waiting out of sight). Advancing moves every book one step: right -> front -> left -> hidden -> right.
 *
 * @param {number} index  Book position in the list.
 * @param {number} active Position of the front book.
 * @param {number} count  Number of books (at least 1).
 * @return {'front'|'right'|'left'|'hidden'}
 */
export function bookRole( index, active, count ) {
	const offset = forwardOffset( index, active, count );
	if ( offset === 0 ) {
		return 'front';
	}
	if ( offset === 1 ) {
		return 'right';
	}
	if ( count >= 3 && offset === count - 1 ) {
		return 'left';
	}
	return 'hidden';
}

/**
 * Signed distance from the active frame: 0, then -1 / +1 for the neighbours, and so on, taking the short way round.
 *
 * @param {number} index  Frame position in the list.
 * @param {number} active Position of the playing frame.
 * @param {number} count  Number of frames (at least 1).
 * @return {number}
 */
export function frameOffset( index, active, count ) {
	const offset = forwardOffset( index, active, count );
	return offset > count / 2 ? offset - count : offset;
}

/**
 * What a film frame is: 'active' (middle, playing), 'prev' (last played, left), 'next' (right) or, further away,
 * 'far-prev' / 'far-next' (out of sight, parked on the side they will slide in from).
 *
 * @param {number} index  Frame position in the list.
 * @param {number} active Position of the playing frame.
 * @param {number} count  Number of frames (at least 1).
 * @return {'active'|'prev'|'next'|'far-prev'|'far-next'}
 */
export function frameRole( index, active, count ) {
	const offset = frameOffset( index, active, count );
	if ( offset === 0 ) {
		return 'active';
	}
	if ( offset === -1 ) {
		return 'prev';
	}
	if ( offset === 1 ) {
		return 'next';
	}
	return offset < 0 ? 'far-prev' : 'far-next';
}

/**
 * Moves a clock forward by `dt` ms, but only while it is running (paused = hover, focus, off screen, a viewer open).
 *
 * @param {number}  elapsed Milliseconds counted so far in this step.
 * @param {number}  dt      Milliseconds since the last frame.
 * @param {boolean} running Whether the clock may move.
 * @param {number}  period  Length of one step in ms.
 * @return {{elapsed:number,advanced:boolean}} `advanced` is true when a step has just ended; `elapsed` restarts from the overshoot.
 */
export function tick( elapsed, dt, running, period ) {
	if ( ! running ) {
		return { elapsed, advanced: false };
	}
	const next = elapsed + dt;
	if ( next >= period ) {
		return { elapsed: next - period, advanced: true };
	}
	return { elapsed: next, advanced: false };
}

/**
 * Small pure helpers for the film strip's running time and progress bar (DPH-016).

/**
 * The running time shown top right of the playing frame: m:ss, counting up, never past the clip's length.
 *
 * @param {number} elapsedMs     Milliseconds since the frame became active.
 * @param {number} lengthSeconds Clip length in seconds, 0 or less when unknown.
 * @return {string}
 */
export function timeLabel( elapsedMs, lengthSeconds ) {
	let seconds = Math.max( 0, Math.floor( elapsedMs / 1000 ) );
	if ( lengthSeconds > 0 ) {
		seconds = Math.min( seconds, Math.floor( lengthSeconds ) );
	}
	return `${ Math.floor( seconds / 60 ) }:${ String( seconds % 60 ).padStart( 2, '0' ) }`;
}

/**
 * How full the progress bar is: elapsed / period, kept between 0 and 1.
 *
 * @param {number} elapsedMs Milliseconds since the frame became active.
 * @param {number} periodMs  Length of the step in ms.
 * @return {number}
 */
export function fraction( elapsedMs, periodMs ) {
	if ( periodMs <= 0 ) {
		return 0;
	}
	return Math.min( 1, Math.max( 0, elapsedMs / periodMs ) );
}

/**
 * Home "Selected work" motion (DPH-013, DPH-016, DPH-017).
 *
 * Two independent rotations: the Documents book fan (every 3.5 s) and the Videos film strip (every 4 s). The
 * Collaterals card has no motion, so nothing here touches it. Opening a book or a frame is not done here: their
 * buttons carry `data-document-id` / `data-video-id` and the modal blocks (placed on the same page) listen for them.
 *
 * Each rotation runs only while its card is on screen, not hovered, not holding keyboard focus, the tab is visible
 * and no <dialog> is open (the Home motion pauses while a viewer is open, DPH-014). With reduced motion nothing
 * moves or plays: the first book and the first clip stay in front.
 */
import { BOOK_PERIOD, FRAME_PERIOD, bookRole, frameRole, tick } from './rotation.js';
import { timeLabel, fraction } from './time.js';

const reducedMotion = window.matchMedia( '(prefers-reduced-motion: reduce)' );
const saveData = () => Boolean( navigator.connection && navigator.connection.saveData );
const viewerOpen = () => document.querySelector( 'dialog[open]' ) !== null;

/**
 * What stops a card's motion. Touch is ignored for hover: a tap leaves a "hover" behind that never ends.
 *
 * @param {Element} card The card element.
 * @return {{hover:boolean,focus:boolean,visible:boolean}}
 */
function watch( card ) {
	const state = { hover: false, focus: false, visible: false };
	card.addEventListener( 'pointerenter', ( event ) => {
		state.hover = event.pointerType !== 'touch';
	} );
	card.addEventListener( 'pointerleave', () => {
		state.hover = false;
	} );
	card.addEventListener( 'focusin', ( event ) => {
		state.focus = event.target.matches( ':focus-visible' );
	} );
	card.addEventListener( 'focusout', () => {
		state.focus = false;
	} );
	if ( 'IntersectionObserver' in window ) {
		new IntersectionObserver( ( entries ) => {
			state.visible = entries[ entries.length - 1 ].isIntersecting;
		}, { threshold: 0.25 } ).observe( card );
	} else {
		state.visible = true;
	}
	return state;
}

const isRunning = ( state ) => state.visible && ! state.hover && ! state.focus && ! document.hidden && ! viewerOpen();

/**
 * Calls `onAdvance` at the end of every `period` ms of running time and `onFrame` on every animation frame.
 *
 * @param {{hover:boolean,focus:boolean,visible:boolean}} state    What `watch()` returned.
 * @param {number}                                        period   Length of one step in ms.
 * @param {() => void}                                    onAdvance Called when a step ends.
 * @param {(elapsed:number, running:boolean) => void}     onFrame   Called on every animation frame.
 */
function loop( state, period, onAdvance, onFrame ) {
	let elapsed = 0;
	let last = performance.now();
	const frame = ( now ) => {
		// A long gap (tab in the background) must not skip several steps at once.
		const dt = Math.min( now - last, 250 );
		last = now;
		const running = isRunning( state );
		const result = tick( elapsed, dt, running, period );
		elapsed = result.elapsed;
		if ( result.advanced ) {
			onAdvance();
		}
		onFrame( elapsed, running );
		window.requestAnimationFrame( frame );
	};
	window.requestAnimationFrame( frame );
}

/**
 * Documents: the book fan (DPH-013).
 *
 * @param {Element} card The Documents card.
 */
function startBooks( card ) {
	const books = Array.from( card.querySelectorAll( '.work-docs__item' ) );
	if ( books.length < 2 || reducedMotion.matches ) {
		return;
	}
	let active = 0;
	const apply = () => {
		books.forEach( ( book, index ) => {
			const role = bookRole( index, active, books.length );
			book.dataset.role = role;
			// Only the front book can be reached and clicked.
			book.toggleAttribute( 'inert', role !== 'front' );
		} );
	};
	loop(
		watch( card ),
		BOOK_PERIOD,
		() => {
			active = ( active + 1 ) % books.length;
			apply();
		},
		() => {}
	);
}

/**
 * Videos: the film strip (DPH-016, DPH-017).
 *
 * @param {Element} card The Videos card.
 */
function startStrip( card ) {
	const frames = Array.from( card.querySelectorAll( '.work-strip__frame' ) );
	if ( frames.length === 0 ) {
		return;
	}
	const still = reducedMotion.matches;
	const state = watch( card );
	let active = 0;
	let loaded = null;

	const unload = ( frame ) => {
		const video = frame.querySelector( '.work-strip__video' );
		if ( video ) {
			video.pause();
			video.removeAttribute( 'src' );
			video.load();
			video.remove();
		}
		frame.classList.remove( 'is-playing' );
	};

	const load = ( frame, src ) => {
		const video = document.createElement( 'video' );
		video.className = 'work-strip__video';
		video.muted = true;
		video.loop = true;
		video.playsInline = true;
		video.preload = 'auto';
		video.tabIndex = -1;
		video.setAttribute( 'muted', '' );
		video.setAttribute( 'playsinline', '' );
		video.setAttribute( 'aria-hidden', 'true' );
		video.addEventListener( 'playing', () => frame.classList.add( 'is-playing' ), { once: true } );
		video.src = src;
		frame.querySelector( '.work-strip__art' ).append( video );
	};

	/** Makes the middle frame the only one holding a video, and plays or pauses it. */
	const syncVideo = ( running ) => {
		const frame = frames[ active ];
		if ( loaded && loaded !== frame ) {
			unload( loaded );
			loaded = null;
		}
		const src = frame.dataset.previewSrc;
		if ( saveData() || ! src || ! state.visible ) {
			return;
		}
		if ( loaded !== frame ) {
			load( frame, src );
			loaded = frame;
		}
		const video = frame.querySelector( '.work-strip__video' );
		if ( video && running ) {
			const started = video.play();
			if ( started && started.catch ) {
				started.catch( () => {} );
			}
		} else if ( video ) {
			video.pause();
		}
	};

	const draw = ( elapsed ) => {
		frames.forEach( ( frame, index ) => {
			const isActive = index === active;
			frame.style.setProperty( '--progress', isActive ? fraction( elapsed, FRAME_PERIOD ).toFixed( 4 ) : '0' );
			const time = frame.querySelector( '.work-strip__time' );
			if ( time && isActive ) {
				time.textContent = timeLabel( elapsed, Number( frame.dataset.length ) || 0 );
			}
		} );
	};

	const apply = () => {
		frames.forEach( ( frame, index ) => {
			const role = frameRole( index, active, frames.length );
			frame.dataset.role = role;
			// Only the middle frame can be reached and clicked.
			frame.toggleAttribute( 'inert', role !== 'active' );
		} );
		draw( 0 );
	};

	if ( still ) {
		// Nothing moves or plays: the first clip stays in the middle as a poster.
		draw( 0 );
		return;
	}

	let lastRunning = null;
	let lastVisible = null;
	loop(
		state,
		FRAME_PERIOD,
		() => {
			active = ( active + 1 ) % frames.length;
			apply();
			lastRunning = null;
		},
		( elapsed, running ) => {
			draw( elapsed );
			if ( running !== lastRunning || state.visible !== lastVisible ) {
				lastRunning = running;
				lastVisible = state.visible;
				syncVideo( running );
			}
		}
	);
}

document.querySelectorAll( '.work-card--videos' ).forEach( startStrip );

	 * Create a collateral.
	 *
	 * @param string $title     Title.
	 * @param int    $order     Menu order.
	 * @param bool   $highlight Whether it is picked for Selected work.
	 * @param string $paper     Paper size (a landscape paper size makes a wide blank preview).
	 * @return int Post ID.
	 */
	private function make_collateral( string $title, int $order = 0, bool $highlight = true, string $paper = 'A4' ): int {
		$id = self::factory()->post->create(
			array(

	}

	private function xpath( string $html ): DOMXPath {
		$dom = new DOMDocument();
		libxml_use_internal_errors( true );
		$dom->loadHTML( '<?xml encoding="utf-8"?>' . $html );
		libxml_clear_errors();

		return new DOMXPath( $dom );
	}

	private function xpath_in( DOMNode $node, string $query ): DOMNodeList {
		return ( new DOMXPath( $node->ownerDocument ) )->query( $query, $node );
	}

	private function file( string $relative ): string {
		$path = $this->theme_dir() . '/' . $relative;
		$this->assertFileExists( $path );

		return (string) file_get_contents( $path );
	}

	/**
	 * The text of a CSS rule or at-rule body that starts with `$selector {`.
	 *
	 * @param string $css      Stylesheet.
	 * @param string $selector Exact selector text.
	 * @return string The declarations, or '' when the rule is not there.
	 */
	private function rule( string $css, string $selector ): string {
		// A rule starts at the beginning of the file or right after a `}`, a `{` (an at-rule opening) or a comment.
		if ( preg_match( '/(?:^|[{}\/])\s*' . preg_quote( $selector, '/' ) . '\s*\{([^}]*)\}/', $css, $m ) ) {
			return $m[1];
		}

		return '';
	}

## 11. Risks and open questions (none block implementation)

- **Data, not code, decides what Home shows.** Until the owner ticks "Mark as highlight (Selected work)" on 4 documents, 5 videos and the collaterals, the cards show text only (D1). The `documents` seeder has no `highlight` column; adding one is a small plugin ticket if the owner wants seeded Home data.
- **DPH-010 AC4 against DPH-012 AC5 and DPH-016 AC5.** "Under 620px the visual drops under the text" and "on phones the fan stays on the right" can not both hold literally; D4 stacks the visual and aligns it right. Owner: confirm, or say the phone fan and strip should stay beside the text (then the 620px stack applies to Collaterals only).
- **Card width.** The stories say "about 480px" (the wireframe's 980px page); the cards follow the Home shell (D3), so they are wider on large screens.
- **Real preview clips.** Videos that are embed only show their poster for ever (no way to preview an embed without loading a third-party player, which the story forbids). Upload files (or the 6 s preview clip) for the ticked videos if the owner wants motion.
- **Payload size.** All three modal blocks write the data of every published document and collateral into Home, as on their own pages. Fine at today's sizes; a later ticket could limit them to the ticked posts if the libraries grow large.
- **Two viewers on one page.** Each modal listens to `popstate` for its own query parameter only (`document_slug`, `collateral_slug`, `video_slug`), so opening one does not touch the other; the section 6 viewer lines are the proof (the URL is cleaned after each close).
- **`inert` on the side books** keeps them out of the tab order and out of reach; they are decoration by design (D6).
- **Video viewer without a tile.** The Videos modal's fly-out needs a Videos-page tile; on Home it uses its fade (D10). If the owner wants the fly-out from the frame, that is a change to `video-modal/view.js` (look up the opener, not only `.videos-item__open`) and is not done here.
