## Resolved decisions
| Topic | Decision |
|---|---|
| Aspect ratio | Taxonomy `aspect_ratio` (DPB-018) wins. No `cptdp_aspect_ratio` meta, no `21:9`, no `:` form. Terms `16x9`, `9x16`, `1x1`, `4x3`. |
| Post statistics | Rows `{ label, value }` strings (DPB-011), added on top of the Video CPT in its own phase. |
| Aspect ratio default | Default term `16x9`. Terms editable under Videos menu. |
| Video Category | Keep default flat tag box (multi). |
| Software tools | One array meta row `cptdp_software_tools`. |
| Editor | Classic, same as other CPTs. |
| Video file / embed | Both optional, no "at least one" validation. |
| Build order | Aspect ratio first (Video attaches it), then Video, then statistics. This reorders the version map vs the source plans, see Versions. |
