# Software tool icons

One square PNG per software tool, 128 x 128, transparent background, the tool's mark only (no wordmark).
The file name is the tool's slug (`sanitize_title( title )`). Tools with no row file here get the
two-letter monogram in the theme (DPH-024) and are seeded without an icon.

Images are built with `bin/build-tool-icons.php` (plan DPH-024, step C4) from the sources below. The
logos are trademarks: the owner must review this list before launch. A tool with no clean source
ships without a file rather than with a doubtful one.

Simple Icons artwork is CC0. The trademarks stay with their owners, and their brand guidelines still apply.
